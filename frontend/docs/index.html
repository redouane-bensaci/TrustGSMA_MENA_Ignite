Integrating TRUST

One API endpoint gives your business real-time mobile network verification without needing to build or maintain complex carrier integrations.

Quickstart (cURL)

curl -X POST https://api.trust.dz/v1/verify \
  -H "Authorization: Bearer tr_test_9941a8" \
  -H "Content-Type: application/json" \
  -d '{
    "event_type": "order_placement",
    "amount": { "value": 74000, "currency": "DZD" },
    "counterparty": {
      "msisdn": "+213661448899",
      "declared_name": "Yacine Mansouri",
      "declared_location": { "cell": "31-ORN", "label": "Oran" }
    },
    "channel": "api",
    "idempotency_key": "ord_88213"
  }'

The 6 CAMARA Network Tools

TRUST autonomously selects which of these six GSMA Open Gateway APIs to query via Nokia Network as Code:

1. Number Verification (camara:number-verification:v1) COST: 1 UNIT

Proves the mobile session matches the claimed carrier subscription without sending vulnerable SMS OTPs.

2. Device Status & Roaming (camara:device-status:v1) COST: 1 UNIT

Queries HLR/VLR to ensure a physical device is live, registered, and not roaming unexpectedly.

3. SIM Swap Probe (camara:sim-swap:v1) COST: 2 UNITS

Checks carrier records for recent SIM replacements or port-outs, detecting account takeovers instantly.

4. Device Location Verification (camara:device-location:v1) COST: 1 UNIT

Compares the handset's serving cell tower with the delivery or withdrawal address, catching spoofed VPNs.

5. Carrier KYC Match (camara:kyc-match:v1) COST: 2 UNITS

Validates national ID and legal name against telecom subscriber contracts filed with operators.

6. Number Recycling Check (camara:number-recycling:v1) COST: 1 UNIT

Verifies whether an orphaned MSISDN was reassigned to a new subscriber to prevent credential leakages.
