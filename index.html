THE ASYMMETRY EVERY CHECKLIST IGNORES

A fixed rule set costs the same to guard 2,000 DZD and 200,000 DZD.

How it decides.

01

Binding

Before anything else: is this device still the device the number lives on? A SIM that moved 14 hours ago is not the same identity, no matter what the password says.

02

Registry

The other end of the transfer has a history it didn't choose: age, cluster, how many strangers paid it this week. You can rename an account. You can't rename its graph.

03

Budget

Every call costs units, and the agent knows what the transaction is worth. Cheap questions first. Expensive ones only when the cheap answers disagree.

04

The loop

Think, call, observe, think again. Not a pipeline — a loop that can change its mind halfway through and buy one more signal.

05

Verdict

Approve, review, hold — with the trace attached. If you can't read why it decided, it didn't decide, it guessed.
